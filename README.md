# Fahad Khan — Portfolio

A static portfolio site built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content
- `style.css` — styles
- `script.js` — nav toggle + scroll-spy

## Deploy with GitHub Pages

1. Create a new repository on GitHub, e.g. `fahadkhan00.github.io` (using this exact name gives you a live site at `https://fahadkhan00.github.io`) — or any repo name if you're fine with a `/reponame` URL suffix.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root (drag-and-drop on the GitHub web UI works, or use `git push`).
3. Go to the repo's **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to `Deploy from a branch`, choose the `main` branch and `/ (root)` folder, then save.
5. Wait a minute or two — GitHub will give you the live URL at the top of the Pages settings.
